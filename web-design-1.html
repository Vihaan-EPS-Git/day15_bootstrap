    Math Science Web Design 1: From the Ground Up

This is the Web Design 1 Course:

Course Syllabus: Web Design (Fall / Spring Semester)
Instructor: Prof. Henderson | Email: shenderson@school.edu | Room: 305

📚 Course Description: Web Design introduces students to the principles and practices of creating modern, responsive, and user-friendly websites. Students will learn front-end development languages, UI/UX design fundamentals, wireframing, and modern frameworks through hands-on coding projects.

🎯 Course Objectives:
• Master core web technologies including HTML5, CSS3, and foundational JavaScript.
• Apply responsive design principles to ensure websites look great on all devices.
• Understand user experience (UX) and user interface (UI) design best practices.
• Utilize modern styling frameworks like Bootstrap for rapid layout creation.

📅 Weekly Course Outline:
• Weeks 1-3 (Introduction to HTML & Structure): Basic document layout, semantic tags, forms, and multimedia elements.
• Weeks 4-7 (CSS Styling & Layouts): Selectors, the box model, Flexbox, CSS Grid, and responsive media queries.
• Weeks 8-11 (UI/UX Principles & Frameworks): Wireframing, accessibility (WCAG), color theory, typography, and working with Bootstrap.
• Weeks 12-15 (Interactive JavaScript Basics): DOM manipulation, event handling, and adding dynamic behaviors to web pages.
• Weeks 16-18 (Deployment & Portfolio): Domain hosting, version control with Git, and publishing live websites.
• Weeks 19-20 (Final Review & Capstone Project): Final showcase of a multi-page responsive portfolio website.

📝 Grading Policy: Coding Projects: 40% | Quizzes & Exams: 25% | Final Capstone Project: 25% | Class Participation: 10%

🎒 Required Materials: Computer with internet access, Text Editor (VS Code recommended), Modern Web Browser (Chrome / Firefox).
